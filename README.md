# DevOps Assignments

## Project Description
This repository contains practice assignments for learning Linux, Git, and DevOps fundamentals.

## Files and Scripts
- `.gitignore` — Specifies files Git should ignore, including `.log`, `.tar.gz`, and `.gz` files.
- `README.md` — Describes the project and explains how to use the repository.

## How to Run
This repository currently contains Git configuration and documentation files. Use the following commands to check the repository:

```bash
git status
git log --oneline
cat README.md
```

## Purpose
To practice Git commands, repository management, commits, and GitHub integration.
